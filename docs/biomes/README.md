## How the images are made

* **Satellite:** Sentinel-2 cloudless mosaics by EOX (2016: CC BY 4.0; 2024 where the 2016 mosaic is unusable: CC BY-NC-SA 4.0) or NASA GIBS MODIS imagery (public domain) where Sentinel-2 has no data, framed on the catalogued coordinate (see [places.md](../places.md)). Each page names its source.
* **In-game map:** the site in the seed-0 world, rendered from the generated chunks with block map colours and hill shading (`./gradlew :26.2:runSelfCheck -Pmaps=<plan.json>`, plan from `tools/gallery/plan.py`).
* **In-game view:** Minecraft 26.2 with Sodium, Iris (Bliss shaders) and Voxy LODs, taken in the same world by the dev screenshot director (`./gradlew :26.2:runShots -Pplan=shots.json -PclientMods=<dir>`), then `tools/gallery/collect.py`.
